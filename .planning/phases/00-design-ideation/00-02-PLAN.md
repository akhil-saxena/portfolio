   `- one-liner:` must have a payload of 60–110 characters and every line beginning
   `- card:` must have a payload of 120–200 characters. Report the actual count against the
   bound that was broken.

3. **Guess visibility (D-40 rule 2).** Inside a `[NEEDS AKHIL]` block, any bare digit run of
   two or more characters that is not already wrapped in angle brackets is a violation — a
   guess that looks like a fact is worse than a gap. Angle-bracket slots such as
   `<n> applications`, `since <month>`, `<metric>` are the sanctioned form.

Follow the fail-loud convention: never `console.warn` and exit 0. On any violation print
each one on its own line naming the failure mode, then `process.exit(1)`. On success print
the number of files scanned, the number of `[NEEDS AKHIL]` markers found, and their minimum
word count, then exit 0.

Create the `00-COPY/` directory as part of this task so the checker has a target to walk;

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sibling repos (`../cairn`, `../hued`, `../Momentum`, `../TimeShift`, `../design-system`) → committed copy | Facts cross from local repositories into text that will be published on a public site and read by engineers who can open those repos. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-07 | Information Disclosure | copy drafted from private repository contents | mitigate | Only facts already public in a README, CHANGELOG or store listing may be quoted. Nothing from a `.env`, a runbook, a private analytics figure or an unreleased plan enters the copy. The `- source:` line on every entry makes the provenance auditable, so a reviewer can spot a fact that should not be public. |
| T-00-08 | Repudiation (reputational, not protocol) | stale or invented facts in published copy | mitigate | Every number must be read out of a file this session. `../design-system/.planning/PROJECT.md` is explicitly excluded as stale (Pitfall 7), and the handoff's "55 components" is asserted absent. `[NEEDS AKHIL]` plus angle-bracket slots is the sanctioned form for anything not sourced — the checker enforces that a guess never looks like a fact. |
| — | Spoofing | — | not applicable | No authentication, session or identity surface exists in this plan. |
| — | Tampering | — | not applicable | No package is installed, no dependency is added, no executable input is accepted. The one script created reads only committed Markdown from a fixed path inside the repository. |
| — | Denial of Service | — | not applicable | Nothing is served; the checker is a local, bounded file walk. |
| — | Elevation of Privilege | — | not applicable | No privilege boundary is crossed; no credential, binding or platform resource is touched. |
| T-00-SC | Tampering | npm/pip/cargo installs | not applicable | This plan installs no package. `check-copy-length.mjs` uses only `node:fs` and `node:path`. The supply-chain gate is not triggered. |
