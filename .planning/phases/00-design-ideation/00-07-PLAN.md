Measured during research and verified against `../design-system` on 2026-08-17:

Cascade specificity — D-27's arithmetic is correct and is not the problem:
- `:root` (0,1,0) · `.dark` (0,1,0) · `:root.dark` (0,2,0)
- `:root[data-brand="charcoal"]` (0,2,0) · `:root[data-brand="charcoal"].dark` (0,3,0)

Astro CSS ordering: within the imported-styles category, order is decided by `cssOrder(a,b)`
in `astro/dist/core/build/runtime.js`, sorting by accumulated import index ascending then
module-graph depth descending. The import index is literally the position of the `import`
statement inside the importing module — swapping two adjacent imports flips the emitted order
every time. Island CSS is HOISTED out of the island into a page-level stylesheet, so it
competes in the same cascade bucket as `.astro` imports; there is no separate island cascade.
`build.inlineStylesheets: 'auto'` inlines any sheet under Vite's 4 kB limit as a `<style>`
tag and links the rest; order was preserved identically under `'auto'` and `'never'`.

Current `exports` map — `themes` and `fonts` DO NOT exist today (verified by reading
`../design-system/package.json`): `.`, `./hooks`, `./icons`, `./tokens.css`,
`./primitives.css`, `./utilities.css`, `./css/*`.

Proposed additions (purely additive, not the breaking part of v2.0.0):
`"./themes/*.css"` and `"./fonts/*.css"`, each mapping `style` and `default` to
`./dist/themes/*.css` and `./dist/fonts/*.css`. Spelling the wildcard WITH the `.css`
extension is what makes `@akhil-saxena/design-system/themes/charcoal.css` — the exact string
D-35 specifies — resolve, and avoids the double-extension trap the existing `./css/*` entry
has.

The extensionless trap, measured: `/css/base.css` resolves to `dist/css/base.css.css` and
fails the Rolldown build; `/css/base` resolves correctly. `import.meta.resolve()` reports the
broken form as resolvable because it substitutes the pattern without stat-ing the target, so
a Node-level check passes while `astro build` fails.

`dist/css/` holds 74 sheets. Verified names relevant to the manifest include: `base`,
`text`, `heading`, `eyebrow`, `link`, `divider`, `card`, `chip`, `button`, `appbar`,
`footer`, `timeline`, `lightbox`, `statuspill`, `segmentedcontrol`, `appshell`, `datagrid`,
`field`, `textinput`, `textarea`, `select`, `checkbox`, `radio`, `toggle`, `numberstepper`,
`sortable`, `richtext`, `sheet`, `modal`, `emptystate`, `skeleton`, `progressbar`,
`formvalidation`, `inlineedit`, `relativetime`, `alertbanner`, `table`, `tabs`, `wizard`.

Research's plausible-manifest baseline: public set (base plus 13 component sheets) measured
41,281 B raw / 8,923 B gzip; a plausible admin-extra set of 24 further sheets adds 73,654 B.
`primitives.css` whole is 178,398 B raw / 35,098 B gzip.
