<interfaces>
The coverage contract, from UI-SPEC §"Machine-generating the matrix". Every admin route already
exports, from plans 12 to 15:

```astro
export const SCREEN = { id, route, entity, layouts };
export const STATES = [
  { state: "populated", coverage: "designed",  ref: "S-photos" },
  { state: "empty",     coverage: "designed",  ref: "E-photos" },
  { state: "loading",   coverage: "inherits",  ref: "T-loading-list" },
  ...
];
```

Cell vocabulary, exactly three values: `designed` (a sketch exists for this exact cell — must
carry a link to the artefact ID), `inherits: T-n` (covered by a treatment sketched elsewhere —
must carry the treatment ID), `n/a: <reason>` (this cell cannot occur — must carry a one-clause
reason). **A blank cell fails review**, and that single rule is what converts D-03's
"exhaustively" from an aspiration into a checkable property.

`CANONICAL_SCREENS` has 7 entries; `CANONICAL_STATES` has 6 (`empty`, `loading`, `error`,
`dirty`, `conflict`, `success`) — `populated` is the row header carried by the `S-` artefact, not
a cell. 7 x 6 = 42.

Phone contract, D-09: exactly **four** permitted capabilities (review pending changes, fix text,
reorder photos, publish) and **two** refusals (the crop picker and case-study authoring, both
already sketched in plans 14 and 15). Part 3 is therefore a **6-row list**, not a 7x multiplier
on the matrix. Viewport 390x844, charcoal LIGHT, **comfortable** density — 30px controls sit
under the 44px touch floor D-09 implies.

DS composition per UI-SPEC:
- Publish confirm, valid (D-14) — `ConfirmDialog tone="neutral"` listing changed items
- Publish confirm, invalid (D-18) — `Modal` + `FormErrorSummary` deep-linking to the offending
  screen. `FormErrorSummaryProps` is `{ errors: string[]; title?: string; className?: string }`
  (`dist/index.d.ts:3350-3354`) — **no `href`**, so the deep link is impossible. That is **G-6**,
  and this overlay is its evidence.
- Discard this screen (D-17) — `ConfirmDialog tone="danger"`
- Discard all (D-17) — `TypeToConfirm guardWord="discard"`
- Phone sidebar (D-09) — `Sheet side="left"`

Existing `00-FINDINGS.md` rows, seeded by plans 01, 04, 07, 09 and 11 from UI-SPEC's 16-row gap
