## Task 1 — the loader

`loadStudy(slug, tier)` → `loadStudy(slug)`. The tier-keyed `REQUIRED_HEADINGS` object becomes
one sequence whose middle entry is an array: `["Problem", MIDDLE_HEADINGS, "Outcome", "Assets"]`,
with `MIDDLE_HEADINGS = ["Decisions", "Decision"]` exported so the error message prints both
without a second literal. Deliberately the same shape `check-case-length.mjs` already used, so
the build-time loader and the standalone gate cannot disagree about what a required section is.

Every existing throw survives and three were added:

| Throw | Kept / new |

| Neither middle spelling — names both and the headings found | kept, message rewritten |

**The band assertion measures `bandWords`, not `words`.** A second count was added that drops

## Task 3 — both controls

Both against the real `astro build`, on `case-timeshift.md`, SHA-256
`1c1599b7176d210c5a7fca6d2e3a77204e430ed0c3026d441d8a6e1505010ff1`, **restored byte-identically
both times**.

**Mutated with Node, not `sed`.** This is macOS: BSD sed, and `sed -i '' '0,/re/s//X/'` is a
**silent no-op** — it accepts the syntax, changes nothing, and exits 0. A control that mutated
that way and then asserted a PASS would certify a control that never ran. The mutation reads the
original bytes into a Buffer, writes the edit, runs the build, and writes the Buffer back, so
byte-identity is guaranteed by construction *and* verified by hash. Assertions are on the build's
exit code and printed message — behaviour, not substring — never `grep -c` on the edited string.

**Control 1 (negative), `## Decisions` → `## Findings`:** build exit **1**, message
`must carry ONE of the headings "## Decisions" or "## Decision", and carries neither`, printing
`## Problem | ## Findings | ## Outcome | ## Assets` as found. SHA identical after restore.

**Control 2 (positive), `## Decisions` → `## Decision`:** build exit **0**, 92 pages. The
singular heading rendered (`>Decision<` ×1, `>Decisions<` ×0), the middle section kept its prose,
the header readout printed `## Decision · no register entries`, and the inline figure **still
attached**. SHA identical after restore.

Control 2 caught something the plan did not anticipate and the route was written to survive:
the asset plan writes `section: MIDDLE`, a sentinel resolved at render to whichever spelling the
draft used. Hard-coding `"Decisions"` would work today and would silently drop the figure from
any singular draft — the figure list is a *filter*, so a section name matching nothing yields no
figure and **no error**. Same class of silent drop the loader exists to prevent, one layer up,
and only a positive control can reach it.

## Deviations from Plan

### Auto-fixed

**1. [Rule 3 — blocking] Astro hoists `getStaticPaths` above the frontmatter**
- **Found during:** Task 2
- **Issue:** the route's first draft held the five ids in a local `const`; the build failed with
  `STUDIES is not defined`, pointing at Astro's own `route-cache.js`. `getStaticPaths` is hoisted
  above the frontmatter, so a `const` declared there is in the temporal dead zone when it runs.
- **Fix:** the array moved to `artefacts.mjs` as `CASE_STUDIES`, which is a better home anyway —
  an id that is both a route and an artefact belongs with the artefacts. Recorded in a comment
  because the error message is nowhere near the mistake.

**2. [Rule 2 — missing critical functionality] Corpus membership asserted in two places**
- **Found during:** EXTRA 2 and Task 2
- **Issue:** two ways for the corpus and the routes to disagree silently. `check-case-length.mjs`
  scanned whatever `case-*.md` it found and enforced only the slugs in `OWNED` — which is how six
  case files, two of them the same study, produced an **exit 0 run that printed "OVER band" on
  its own stdout**. And `CANONICAL_IDS` could carry an `X-case-*` id with no study, or miss one,
  producing a screenshot set with a design silently absent.
- **Fix:** `check-case-length.mjs` gained rule 2b — a missing study and an unknown study are
  separate failures with separate messages. `artefacts.mjs` gained an import-time reconciliation
  between `CASE_STUDIES` and `CANONICAL_IDS`, so it fires in the build *and* in every check script
  that imports the module, including ones that still run when the build cannot complete.
- **Both negative controls run:** a planted `case-hued-COMPRESSED.md` → exit 1 `UNKNOWN-STUDY`; a
  removed `case-momentum.md` → exit 1 `MISSING-STUDY`; directory listing hash identical after
  restore, `git status --porcelain` empty for the path, gate back to exit 0.

**3. [Rule 1 — bug] The two band counters disagreed by 3 words**
- **Found during:** Task 1
- **Issue:** the loader read cairn at 689 against the gate's 692 and design-system at 594 against
  597, agreeing exactly on the three studies with no register. One word per numbered `###`: the
  loader parses `### 3. Multi-tenancy…` into an ordinal and a title, so the ordinal never reached
  the count. Three words is nothing until a draft sits within three of a band edge, and then it is
  a build that fails against a gate that passes.
- **Fix:** the ordinal counts. Both now report **597 · 692 · 619 · 682 · 647**. Two numbers for
  one contract was the defect; which one was "right" is not the interesting question.

**4. [Rule 2 — accessibility] 11 of 17 44px offenders per class are `case.css`'s**
- **Found during:** Task 3
- **Fix:** `(pointer: coarse)` block on the hit area — `.case-index a`, `.case-index-end a`,
  `.case-toggle input`. Keyed on pointer and never on width, because a 1440 touch laptop needs the
  floor and a 390px desktop window does not.

**5. [Rule 1 — bug] H-scroll at 344 on two routes**
- **Found during:** Task 3
- **Fix:** `overflow-wrap: anywhere` on `.case-code`. See the audit section above.

**6. [Judgement] `CaseChrome`'s jump list became the corpus index**
- With one study per route there is nothing on the page to jump to, so the list would have been a
  single self-link. It now takes an optional `href` and a `current` flag and lists all five
  routes, and the end-of-page footer carries the same list plus a link back to `/work`. Without
  it, five routes would be five orphans — a navigation defect the routing change creates.

**7. [Judgement] The end-of-page footer text was rewritten**
- Both retired templates closed with "In Phase 5 each becomes its own page". That future is this
  plan, so the paragraph was false the moment the routes landed.
