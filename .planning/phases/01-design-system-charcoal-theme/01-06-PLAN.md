**G-12, and why `./css/*` cannot simply be respelled.** The existing entry's wildcard already
supplies `.css`, so `…/css/base.css` expands to `dist/css/base.css.css` — a file that does not
exist — and the Rolldown build fails, while `…/css/base` expands correctly. The trap is that the
**broken form is the one every developer writes first**, and `import.meta.resolve()` does **not**
catch it: it substitutes the wildcard and reports a path without checking the file exists. Fix by
**adding** `"./css/*.css": { "style": "./dist/css/*.css", "default": "./dist/css/*.css" }`
alongside the existing pattern, so both spellings work. Do not remove or change `"./css/*"` —
D-33's manifests are written extensionless and Phase 5 consumes them.

**`scripts/postbuild.mjs`**, the copy loop to extend, and its own stated reason for throwing:

```js
// package.json `exports` maps ./tokens.css, ./primitives.css and
// ./utilities.css directly at these paths, so a silent failure here publishes a
// package whose documented stylesheet entrypoints 404. Throwing is the point.
for (const css of ["tokens.css", "primitives.css", "utilities.css"]) {
  copyFileSync(join(root, "src", css), join(dist, css));
}
```

It also runs `scripts/split-css.mjs` (step 2) and stamps `"use client"` on every emitted `.js`
(step 3), with a guard that **throws if it stamps zero files**. Match that voice: a new failure
mode gets a check that throws with a message naming what broke and what it costs.

**`src/packaging.test.ts` covers the new entries for free**, and its wildcard branch is why:

```js
if (value.includes("*")) {
  const [dir = "", suffix = ""] = value.split("*");
  const matches = existsSync(join(root, dir)) && readdirSync(join(root, dir)).some(f => f.endsWith(suffix));
  ...
}
```

For `"./dist/themes/*.css"` that becomes *does `dist/themes/` exist and hold at least one `.css`* —
exactly the assertion needed, with no new test to write. The suite is `describe.skipIf(!built)`, so
it only runs after a build; `prepublishOnly` runs `build && test`, which is the path that matters.

**Extend `postbuild.mjs`.** The existing loop copies three flat files; `themes/` and `fonts/` are

and holds at least one match; a build that copied one of two theme files would pass that assertion
and publish a half-empty directory. Belt and braces, and it costs three lines.

should report the real count, since the whole point of this plan is that the count grew.
