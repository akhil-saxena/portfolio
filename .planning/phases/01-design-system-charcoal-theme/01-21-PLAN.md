<objective>
Publish **v2.0.0** to the public npm registry, then re-measure DS-09 against the **registry tarball** and
record the verdict in this repository's phase directory.

Purpose: this is DS-08, and it is the plan that turns everything before it from a branch into a thing
Phase 5 can install. Success criterion 1 is explicit that a local path or a tarball does not count:

> `npm install @akhil-saxena/design-system@<new version>` **from the public registry** yields a working
> charcoal theme consumable by version number, **no local path or tarball required**.

The version is a **major** because 01-04 removed `@font-face` from `tokens.css`, which is a definite
break for Cairn. *"Semver telling the truth is the mitigation, not a footnote."*

And the closing act is a re-measurement rather than a declaration. G-15 was a load-bearing assumption
that *"sat in `.planning/` as an unmeasured claim for the whole project"* — the register's own
`Evidence` column exists because of it. So DS-09 does not close on the strength of 01-08's tarball run;
it closes on the **published artefact**, measured with `check-bundle.mjs`, the same script that produced
the finding.

`autonomous: false`. Publishing is irreversible in practice — npm unpublish is heavily restricted — and
the credentials are the user's.

Output: a live registry version, a merged branch, and a recorded DS-09 verdict.
</objective>

  `packaging.test.ts` is `describe.skipIf(!built)`, and this is the path where it is live: its

**`check-bundle.mjs`** — the DS-09 measurement. It walks `dist/_astro/*.js.map` `sources` arrays,
counts modules per heavy family, and reports raw and gzip bytes. Three things to hold onto:

- `lucide-react` is deliberately **excluded** from the failure set; the failure set is
  prosemirror / tiptap / lowlight / highlightjs / dndkit.
- Its 50 KB gzip budget is **research assumption A8, explicitly UNCONFIRMED**, and its own header says
  it must not be hardened into a gate until a human settles it. **Read the report; do not trust the
  exit code.**
- It exits `2` with a diagnostic if `dist/_astro` is missing or if no `.js.map` exists — the latter
  meaning the probe island lost its `client:load` directive, so a static page was measured and proved
  nothing.

**The G-15 baseline to compare against**, measured at `astro@7.2.2` / `@astrojs/react@6.0.2` /
`react@19.2.8` / DS `1.11.4`:

unchanged filename, but Vite's dependency cache is keyed independently of npm's integrity check.
