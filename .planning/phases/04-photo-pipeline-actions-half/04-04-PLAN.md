<objective>
Put the image toolchain and its test fixtures in place, and settle the two dependency decisions
before anything is written against them.

`sharp` is already resolved at 0.35.3 transitively via `astro@7.2.2`, and the committed
`package-lock.json` (lockfileVersion 3, generated on darwin-arm64) already contains
`node_modules/@img/sharp-linux-x64` and `@img/sharp-libvips-linux-x64` — verified by grepping the
lockfile, not assumed. So `npm ci` on `ubuntu-latest` resolves the prebuilt Linux binary and there
is **no native build on the runner**. Relying on a transitive resolution for a pipeline's core
dependency is still wrong, so this plan makes it direct and pinned.

Purpose: PIPE-01. 04-07 cannot write a derivation module without sharp, an EXIF reader, and
fixtures that exercise the three cases that matter — rich EXIF, no EXIF at all, and a source
already smaller than the 400px variant (the `withoutEnlargement` case, which is the one a naive
resize gets wrong by upscaling).
Output: two or three pinned devDependencies, a committed fixture generator, three fixtures, an
independent expectation table, and a test proving each fixture is what it claims.
</objective>

<interfaces>
From `src/lib/photo-pipeline.ts` (created in 04-02) — the variant table these fixtures must
exercise:
  VARIANTS: original(2000,q85) large(1200,q85) medium(800,q85) small(400,q80)
  THUMB: width 40, quality 60, `data:image/webp;base64,` prefix

The six EXIF fields `PhotoExifSchema` requires — all NULLABLE, none optional, so a file with no
EXIF must still yield a complete six-key object:
  camera       <- [Make, Model].filter(Boolean).join(' ')   null when the join is empty
  lens         <- LensModel                                  null when absent
  aperture     <- `f/${FNumber}`                             null when FNumber is falsy
  shutter      <- ExposureTime < 1 ? `1/${Math.round(1/t)}` : `${t}s`
  iso          <- ISO (a number, z.number().int().positive().nullable())
  focalLength  <- `${FocalLength}mm`

Null census across the 39 committed records, measured:
  camera=1  lens=11  aperture=2  shutter=2  iso=2  focalLength=2

The legacy extractor, for reference (`git show legacy/nextjs-portfolio:scripts/process-images.js`):
  exifr.parse(filePath, { pick: ['Make','Model','LensModel','FNumber','ExposureTime','ISO',
  'FocalLength'], gps: false }) — and it returns null on ANY throw, with the caller substituting
  an all-null object. That behaviour is required, not incidental.

    the data, so an empty dataset cannot silence it.

why, and cover that field with a direct unit test of the mapper against a synthetic parsed object
in 04-07. A fixture that silently exercises five of six fields, with a test named as though it
exercised six, is the shape this project has shipped ten times.
