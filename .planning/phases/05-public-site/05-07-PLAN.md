`FilterNav` (`dist/components/FilterNav.d.ts`), measured:

    FilterNavItem { href: string; label: ReactNode; id?: string }
    FilterNavProps { items; activeHref: string; ariaLabel: string; size?: "sm"|"md"|"lg"; className? }

  - `label` is `ReactNode`, so the per-pill count composes without a second component — but a
    ReactNode inside an ARRAY prop cannot come from an Astro slot, so this needs a `.tsx` wrapper
    rendered with NO `client:*` directive.
  - `activeHref` must match an item `href` EXACTLY: the component does
    `items.findIndex(i => i.href === activeHref)` and, on no match, marks nothing current. Astro's
    directory build format serves `/photos/street/` with a trailing slash. **Normalise
    `Astro.url.pathname` before passing it.** A silent zero is the failure mode.
  - `FilterNav` rejects any href that is not `/`, `#` or `.`-leading and renders it as a
    `<span data-rejected="true">`. All eight hrefs here are root-relative, so none is rejected — but
    a future absolute URL would silently stop being clickable while still looking present.
  - `className` reaches the `<nav>` only. Reaching `.ds-atom-segmented-btn` from the page for
    `scroll-snap-align` is a descendant LAYOUT rule, which QUAL-03 permits — but see OQ-4.
