    StatusPill — generic path (the one to use):
      { tone: "primary"|"secondary"|"muted"|"accent"|"danger"|"success", label: ReactNode,
        withChevron?: boolean, interactive?: never }
    The generic path always renders a `<span>`. Its own docstring: *"A status read out of content is
    not a control — a Live / Maintained / Archived label on a public Work card has nothing to
    activate."* It renders a leading marker whose SHAPE is driven by `data-step`, so the three-way
    split survives greyscale and colour blindness; F-15-5 measured D-45's three statuses at a 1.02:1
    fill separation, and a fill ladder alone would still be a colour distinction. `Badge`'s own
    docstring points here for this case. Do not use `Badge`.

    Card  { variant?: "glass"|"amber"|"dark"|"kanban", padding?, radius?, surface?, hover?: boolean,
            as?: ElementType, children: ReactNode, ...HTMLAttributes }   // className CONCATENATES
    Chip  { tone?, onRemove?, icon?: ReactNode, ...HTMLAttributes }      // className CONCATENATES
    Link  { variant?: "default"|"inline"|"footer"|"action"|"quiet", color?, as?, ... }

    ⚠ `Button` has NO `as` prop (measured: `ButtonProps extends ButtonHTMLAttributes` with
    `variant`, `size`, `loading`, `icon` only). Nothing on this page needs it; plan 05-10 does.

    J1 was CONFIRMED at 44, not 52, on 2026-08-19. `--text-4xl-plus` ships and this page does not
    use it.
