case-sensitive family pattern **cannot fire** on minified output. Both are now case-insensitive and
scoped, but neither is trustworthy on its own: minified Rollup output does not reliably carry npm
package names at all.

control is free: the barrel plant in control #3 must trip **it** too, not only the family patterns —
require that, so the two controls check each other.

legitimately contains `jose`'s crypto and the admin route, so an unscoped assertion 5 either fires on
the server bundle forever or gets loosened until it means nothing.

**The SIX assertions** (§5.3 plus the byte ceiling), verbatim in intent:

  1. Every `dist/client/**/*.html` outside `/photos/` and `/photos/<category>/` contains **zero**
     `<script type="module" src=` referencing an Astro island chunk.
  2. Every such page contains **exactly one** inline script block, and its text matches the theme
     script.
  3. `dist/client/photos/index.html` and each `dist/client/photos/<category>/index.html` contain **exactly one**
     island entry, and it resolves to the Lightbox chunk.
  4. **No public chunk anywhere in `dist/client/` matches
     `/prosemirror|tiptap|lowlight|highlight\.js|dnd-kit/i`.**
  5. `src/lib/photo-pipeline.ts` appears in no client chunk.

Assertion 4 is DS-09's go/no-go re-check. Given §1.1's measurement it should not fire; **the gate
exists because "should not" is not evidence.**
